Privacy Policy

Last updated: September 2026 — this is a translation; in case of doubt, the French version prevails.

This policy describes which data is collected by the bots EAFC-GM, EAFC-ADMIN and EAFC-SERVER, how it is used and stored, and what your rights are.

1. Data collected

The bots only collect the data they need to work:

Data Source Use
Discord ID (user ID) Discord Identify the user in the system
Discord display name Discord Shown in introductions and logs
Gamertag / in-game name Entered by the user Player profile
Gaming platform Entered by the user Player profile
Date of birth / age Entered by the user Player profile
Playing position(s) Entered by the user Player profile
Availability Entered by the user Attendance and call-ups
Experience / competitions Entered by the user Player profile
Sign-up progress Bot (internal) Onboarding follow-up
EA FC club (ID, name) and GM / co-GM role Entered by the user, verified on EA FC Club registration for competitions (EAFC-ADMIN)
Match results and statistics EA FC (public data) Statistics, schedule and standings
Chosen language and bots User's choice Channels shown on EAFC-COMMUNITY (EAFC-SERVER)
Trial or subscription status Discord Bot access per server
Discord server ID and name Discord Data isolation per server
✅ The EAFC bots collect no financial data (payments go through Discord), no password and no email address. They only read private messages sent directly to the bot: a date of birth requested during a player's introduction, or a server owner's reply to a message from the creator, which is forwarded to the creator.

2. Data storage

  • Data is stored on the servers of the host Discloud, in encrypted databases.
  • Data is isolated per Discord server: one server cannot access another server's data.
  • No third-party service is used to store your data.

3. Retention

  • A user's data is deleted automatically when they leave the Discord server.
  • A server's data is deleted when the bot is removed from the server.
  • No data is kept beyond the period of active use.

4. Data sharing

Collected data is never sold or shared for commercial purposes. It is used exclusively to run the bots on your Discord server.

Only exception: automatic translation on the EAFC-COMMUNITY server. The EAFC-SERVER bot translates messages posted in the channels linked between languages (chat, help, announcements). The text of these messages is sent to Mistral AI (France, EU) to be translated, then copied into the channels of the other languages with the author's name and avatar. No other data is transmitted. This only concerns those channels of the EAFC-COMMUNITY server, never the servers where EAFC-GM or EAFC-ADMIN are installed.

5. Your rights

Under the GDPR, you have the following rights:

  • Right of access: you can ask which data concerns you.
  • Right to rectification: you can change your data through the bot's commands (e.g. /presentation).
  • Right to erasure: your data is deleted automatically when you leave the server, or on request through the EAFC-COMMUNITY server.

6. Contact

For any question about your personal data, you can reach us in two ways:

  • Join EAFC-COMMUNITY, the help and news server for EAFC-GM and EAFC-ADMIN: dsc.gg/eafc-community
  • Contact the creator directly on Discord: tootankrton
